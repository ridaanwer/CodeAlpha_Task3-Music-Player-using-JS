# CodeAlpha_Task3-Music-Player-using-JS
Music player interface using HTML & styled with CSS

Features

Audio Controls:* Full play, pause, next, and previous functionality
Track Metadata Display: Dynamically renders song title, artist name, and duration.
Interactive Progress Bar: Tracks current audio duration with seek.
Volume Regulation: Smooth volume slider to control audio.
Playlist Support: Integrated playlist array for dynamic track navigation.
Responsive UI: Styled cleanly for an intuitive user experience across mobile and desktop.
